# Archived generic prediction documentation

Boltz-StFree exposes only the `boltz-stfree screen` structure-free affinity
workflow documented in the project README.

Generic complex structure prediction is intentionally not part of this
product. See the
[separate research/reproduction repository](https://github.com/N283T/boltz2-affinity-interventions-boltz)
for the inherited generic runtime and its documentation.
