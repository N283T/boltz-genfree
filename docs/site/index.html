Install and run

DocsFull guide
1Get the code
$ git clone https://github.com/N283T/boltz-genfree.git
$ cd boltz-genfree
2Install
$ uv sync --frozen --extra cuda
3Screen
$ boltz-genfree screen screen.yaml
→ scores.csv

No install: the browser tool runs in the page on WebGPU. Nothing is uploaded.
