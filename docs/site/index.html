Rank the library. Skip the structures.

Structure-generation-free Boltz-2 affinity screening. It runs the released Boltz-2 affinity trunk and heads directly from processed receptor and ligand inputs, and builds no structure for any candidate.

03

Built for the first pass

GenFree is a cheap first stage: rank the whole library, then spend the full Boltz-2 pipeline only on the top of the ranking.

It builds no structure for any candidate and writes compact scores for large, resumable screens. One run on a single RTX 5080 scored 49,980 compounds of one target in 18,290 s; that shows feasibility on that hardware and target, not general performance.

Input
Receptor sequence (optional A3M MSA) and ligand SMILES from CSV, TSV, SDF, an inline list or CCD codes
Output
scores.csv with affinity_pred_value and affinity_probability_binary per ligand
Weights
Released Boltz-2 affinity checkpoint, downloaded on first use. The browser tool loads a 35 MB conversion of its affinity heads from this site and the trunk weights from Hugging Face
Runs on
CUDA (uv, --extra cuda), or WebGPU in the browser
