# Repository Instructions

- This is an independent repository. Its only writable GitHub remote is
  `https://github.com/N283T/boltz-genfree.git`.
- Pull requests for this repository must target
  `N283T/boltz-genfree`.
- Do not create pull requests against
  `N283T/boltz2-affinity-interventions-boltz`,
  `Novel-Therapeutics/boltz-community`, or `jwohlwend/boltz`.
- Do not add a writable remote for any source or upstream repository.
- Before creating a pull request, verify the base repository explicitly. When
  using GitHub CLI, pass `--repo N283T/boltz-genfree`.
