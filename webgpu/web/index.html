Boltz-GenFree on WebGPU

Protein sequence (+ optional A3M) and a ligand SMILES go through the featuriser, the Boltz-2 trunk and the structure-free affinity module, all written in this repository and run in this page. The 805 MB trunk pack is read lazily by HTTP Range requests, one layer at a time. Serve it with node tools/serve.js (see docs/webgpu.md). Only the ligand conformer mode skip (GenFree's default) is available.
